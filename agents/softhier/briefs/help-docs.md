One tool besides `run`: `docs`, read access to the SoftHier vendor documentation (softhier-sdk's README.md and runtime
headers at the pinned commit, and the RISC-V V extension 1.0 spec). Use it as often as you like; each answer is capped
at 400 lines.

    docs grep PATTERN [DIR]      # extended regex over the pages, or one folder of them
    docs read PATH [FROM [TO]]   # a file, or lines FROM..TO
    docs ls [DIR]
