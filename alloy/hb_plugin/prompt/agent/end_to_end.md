## End to end

1. Read the reference material in your folder, starting with `signature.json`.
2. Call Alloy and `submit` the library it answers with: a correct submission is recorded before you change anything. `score` records nothing.
3. Start from its sources and `Makefile`, improve the loop nests its report flags, `score` each version, and `submit` the ones you keep.
